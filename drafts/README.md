# Drafts

Posts in progress. Each draft starts from `_template.md` and must be linked to a goal (`profile/goals.md`) and a pillar (`profile/editorial-line.md`). If a draft serves neither, it probably should not be posted.

## Naming

```
platform-slug.md
```

No date yet: the date is added when the post is published and moved to `posts/` as `YYYY-MM-DD-platform-slug.md`.

## Workflow

1. Pick an idea from `ideas/backlog.md` and copy `_template.md` here.
2. Fill in the goal, pillar, and target reader before writing.
3. Check the draft against `playbook/learnings.md`, `playbook/hooks.md`, and `playbook/formats.md`.
4. Once published, create the post file in `posts/` and delete the draft.
