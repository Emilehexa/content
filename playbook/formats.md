# Formats

Post formats and when to use them. Each format has a label used in the `format` field of posts.

## Formats

Results from `results/2026-11-first-analysis.md` (small sample).

| Label | Description | Platforms | Best for (goal / topic) | Results so far |
| --- | --- | --- | --- | --- |
| `text` | Text only | LinkedIn, X | TBD | Weakest on both (LinkedIn 31 avg reactions; X 68 avg impressions) |
| `text-image` | Text with an image | LinkedIn | Bottom of funnel so far | 64 avg reactions, 7.6 comments (n=5) |
| `image` | Short text with a photo | X | TBD | 100 avg impressions (n=6) |
| `video` | Short text with a video | LinkedIn, X | TBD | LinkedIn 72 reactions / 23 comments (n=1); X 147 avg impressions |
| `quote-post` | Quoting another post, usually a founder's launch | X | `sf-founders`, `hacker-house` | Best X format: 186 avg impressions, 3.6% engagement (n=12) |

## Structure per format

Copy this block for each format you use.

### Format name

- **Structure:** > hook, body, call to action, length
- **Production effort:** > low / medium / high
- **Notes:** > what you have learned about it

## Formats to try

- Carousel or document post on LinkedIn for middle-of-funnel teardowns (out-of-home campaigns, outbound).
